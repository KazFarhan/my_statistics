# Changelog

## 1.0.0 — 2026-09-29

- First public release.
- Descriptive statistics: mean (arithmetic / weighted / geometric / harmonic),
  median, percentiles, IQR, mode, population & sample variance, standard
  deviation, coefficient of variation, and `Stats.describe()`.
- Eye-catching Flutter charts with no extra chart dependency:
  - `GlowLineChart` — smooth cubic line, gradient area, neon glow, dots.
  - `GlowBarChart` — rounded gradient bars with value labels.
  - `GlowPieChart` — animated donut, glow ring, center label, legend.
- Shared `ChartTheme` presets: `dark`, `midnight`, `sunset`.
- Unit tests for statistics and smoke widget tests for every chart.
- Example gallery app under `example/`.
